## LinkedIn post (English)

I have published FinWise ML Platform on GitHub.

FinWise is a full-stack fintech project that combines credit risk scoring with explainable machine learning and fairness monitoring.

The platform includes:
- Scikit-learn based credit risk scoring
- Model explainability with SHAP
- Fairness and bias monitoring metrics
- Compliance checks aligned with BDDK, Basel III, GDPR/KVKK, and ECOA concerns
- A Flask REST API and Next.js dashboard
- Canary/shadow routing, Prometheus, and Grafana monitoring
- Docker, Kubernetes, and CI/CD infrastructure

This project is intended for educational and research purposes only and must not be used for real financial decisions.

GitHub: https://github.com/berat1834/finwise-ml-platform
